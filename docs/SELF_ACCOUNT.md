# Self Account Feature

The Self Account feature allows you to create personal reading profiles, rate books, and receive personalized recommendations without needing a full user-item matrix retrain. It uses **SVD fold-in** to compute collaborative scores on-the-fly from your ratings.

## How it works

1. **Account Creation**: Create an account with an ID and display name (stored in `data/processed/self_accounts.json`).
2. **Book Search**: Search the catalog by title, author, or keywords.
3. **Add Ratings**: Rate books 1-5 stars. Ratings are persisted to your account.
4. **Recommendations**: The system generates personalized recommendations using:
   - **Collaborative (35%)**: SVD fold-in from your ratings (no full matrix retrain)
   - **Content (30%)**: TF-IDF similarity to books you rated 4+ stars
   - **Readability (15%)**: Difficulty matching to your preferred reading level
   - **Popularity (20%)**: Global Bayesian weighted score

## SVD Fold-in Explanation

Traditional collaborative filtering requires retraining the entire SVD model to add a new user. BookMind uses a **fold-in** technique:

- Your rated books are mapped to their latent factor vectors from the pre-trained SVD model
- A user vector is computed as the weighted average of those book factors
- Recommendations are generated by dot-producting your user vector against all book factor vectors

This gives personalized recommendations in milliseconds without retraining.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/self-accounts` | List all accounts |
| POST | `/self-accounts?account_id=...&name=...` | Create new account |
| GET | `/self-accounts/{account_id}` | Get account details with ratings |
| DELETE | `/self-accounts/{account_id}` | Delete an account |
| POST | `/self-accounts/{account_id}/ratings?book_id=...&rating=...` | Add a rating (1-5) |
| DELETE | `/self-accounts/{account_id}/ratings/{book_id}` | Remove a rating |
| GET | `/self-accounts/{account_id}/recommendations?limit=...` | Get personalized recommendations |
| GET | `/books/search?query=...&limit=...` | Search books by title/author/keywords |

## Demo Usage

1. Open the demo at http://127.0.0.1:8000/demo/
2. Click the **Self Account** tab
3. Click **+ New Account**, enter an ID (e.g., `demo`) and name
4. Search for books in the search box
5. Click a book result to rate it (prompt asks for 1-5 stars)
6. Once you have 2+ ratings, recommendations appear automatically

## File Storage

- **Accounts**: `data/processed/self_accounts.json`
- **Models**: Uses existing `models/collaborative_model.pkl`, `models/content_model.pkl`, `models/popularity_model.pkl`

## Demonstration Tips

For a live demo:
1. Create an account called `demo-user`

3. Rate "The Hunger Games" (book ID 1) with 4 stars
4. Observe recommendations: other Harry Potter books, Catching Fire, similar YA fantasy
